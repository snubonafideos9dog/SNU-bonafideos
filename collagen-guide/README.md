# 콜라겐 재생 치료 및 입원 당일 가이드

상담사가 환자와 함께 화면을 보며 설명하는 상담 도구입니다.
(Vite + 바닐라 JS 컴포넌트 + CSS Modules)

## 두 가지 화면 모드

| 모드 | 용도 | 특징 |
| --- | --- | --- |
| **상담 모드** (기본) | 환자 앞에서 설명할 때 | 한 화면에 한 주제, 본문 18px, 방향키/숫자키로 이동 |
| **요약 한 장** | 전체 조망 · 인쇄 | 4단계를 한 화면에 배치. **인쇄는 항상 이 화면으로 출력됩니다** |

상단 우측에서 전환하며, `#stage-2`, `#summary` 처럼 주소로 바로 열 수도 있습니다.

### 상담 모드 조작

- `←` `→` : 이전 / 다음 단계
- `1` ~ `4` : 해당 단계로 바로 이동
- 상단 진행 레일 클릭 또는 하단 버튼

### 상담 순서 (환자가 실제로 묻는 순서)

1. **어떤 주사제를 맞게 되나요?** — 콜라쉴드 · 새살로 비교
2. **비용은 얼마나 드나요?** — 예상 범위 + 대수별 약제비 표
3. **입원 당일, 하루가 어떻게 진행되나요?** — 7단계 타임라인
4. **보험 서류는 어떻게 받나요?** — 발급 서류 및 절차
5. *(선택)* **자주 묻는 질문** — `faq` 답변을 채우면 자동 추가

> 주사제 대수는 시술 당일 원장님이 초음파로 확인한 뒤 결정되므로,
> 2단계 화면은 확정 금액을 계산하지 않습니다. 대신 **범위로 안내되는 이유**를 먼저 설명하고,
> 대수가 정해졌을 때의 **주사제 약제비만** 표로 보여줍니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 배포 빌드 → dist/
npm run preview  # 빌드 결과 확인
```

## 구조

```
src/
├─ main.js                  # 컴포넌트 조립 + 모드 전환 · 단계 이동
├─ data/content.js          # ★ 모든 문구·금액을 관리하는 단일 파일
├─ lib/icons.js             # 인라인 SVG 아이콘
├─ styles/
│  ├─ tokens.css            # 색상·타이포·간격·그림자 디자인 토큰
│  ├─ reset.css             # 리셋 + 한글 조판 기본값(keep-all)
│  └─ global.css            # 레이아웃(2단 보드) · 리빌 · 인쇄 스타일
└─ components/
   ├─ AppHeader/            # 고정 헤더(모드 전환) + 요약용 히어로
   ├─ StageDeck/            # 상담 모드 덱(진행 레일 · 단계 전환 · 컨트롤)
   ├─ StepSection/          # 요약 화면의 단계 카드 셸(배지 · 제목 · 아이콘)
   ├─ DrugCards/            # 1단계 · 주사제 비교
   ├─ CostBoard/            # 2단계 · 총비용 · 수칙 · 구성 항목
   ├─ PriceMatrix/          # 2단계 · 대수별 주사제 약제비 표
   ├─ DaySchedule/          # 3단계 · 당일 진행 타임라인
   ├─ DocumentGuide/        # 4단계 · 퇴원 서류
   ├─ FaqList/              # (선택) 자주 묻는 질문
   └─ AppFooter/            # 안내 문구
```

각 컴포넌트는 `Component.js`(HTML 템플릿 함수) + `Component.module.css`(스코프 스타일) 한 쌍으로 구성됩니다.
클래스명은 `import s from './X.module.css'` 로 가져와 `s.className` 형태로 사용하므로 이름 충돌이 없습니다.

## 문구·금액 수정

`src/data/content.js` 한 곳만 고치면 화면 전체에 반영됩니다.

| 항목 | 변수 |
| --- | --- |
| 주사제 종류·단가·설명 | `drugs` |
| 시술 전 안내 문구 | `drugNotice` |
| 입원 총비용·비용 구성 | `cost` |
| 시술 후 필수 수칙 | `rules` |
| 당일 진행 일정 | `schedule` (`highlight: true` → 핵심 단계 강조) |
| 퇴원 서류 | `documents`, `documentFlow` |
| 자주 묻는 질문 | `faq` (아래 설명 참고) |
| 대수 안내 문구 | `priceMatrix` |
| 단계 제목 · 환자의 질문 | `steps` |

## 자주 묻는 질문 화면 채우기

`src/data/content.js` 의 `faq` 배열에서 **`answer` 만 채우면** 상담 모드에 화면이 자동으로 생깁니다.

```js
{ icon: 'clock', question: '몇 시에 오고, 언제쯤 끝나나요?', answer: '오전 9시까지 내원하시면 오후 4시경 퇴원하십니다.' },
```

- `answer` 가 비어 있는 질문은 **화면에 나오지 않습니다**
- 모든 답변이 비어 있으면 "자주 묻는 질문" 화면 자체가 생기지 않습니다
- 확인되지 않은 안내가 환자에게 노출되지 않도록 한 장치입니다

## 참고

- 색상·간격·그림자는 `src/styles/tokens.css` 의 CSS 변수로 통일되어 있습니다.
- 우측 상단 **인쇄 / PDF** 버튼은 A4 가로 인쇄용 스타일로 출력됩니다.
- 요약 화면은 1080px 이하에서 1·2·3·4단계 순서로 자연스럽게 쌓입니다.
- 상담 모드의 글자 크기는 `.stageView` 에서 디자인 토큰(`--fs-body` 등)을 덮어써 한 번에 조절합니다.
- 요약 화면에서 숨길 블록은 마크업에 `data-stage-only` 를 붙입니다.
- 헤더의 글자 크기 버튼(가/가/가)은 선택값을 브라우저에 저장해 다음 상담에서도 유지됩니다.
- 본 화면의 금액·일정은 이미지로 전달받은 원본 안내문을 그대로 옮긴 것으로, 실제 안내 전 원내 확인이 필요합니다.
