# 지점별 전용 자료 (clinics/)

`반듯한` 네트워크 지점마다 **다른 파일만** 이 폴더에 넣습니다.
여기에 없는 이미지는 자동으로 공용 원본(저장소 루트 / `en/`)을 사용합니다.

```
clinics/
  bonafide365clinic/          # 반듯한365의원
    비급여항목안내 (1).png
    비급여항목안내 (2).png
    원내서류안내_A4.png
    en/                       # 영문판이 따로 있을 때만
      비급여항목안내 (1).png
      ...
```

## 파일 찾는 순서 (js/clinic.js)

```
clinics/<지점>/en/<파일>  →  clinics/<지점>/<파일>  →  en/<파일>  →  <파일>
```

## 주의: 가격표는 공용으로 내려가지 않습니다

`js/clinic.js` 의 `CLINIC_ONLY_IMAGES` 에 등록된 파일(비급여항목안내·원내서류안내)은
해당 지점 폴더에 없으면 **다른 지점 가격표를 대신 보여주지 않고** "준비 중" 안내를 띄웁니다.
환자에게 틀린 가격이 노출되는 사고를 막기 위한 장치입니다.

## 지점 추가하는 법

1. `js/clinic.js` 의 `CLINICS` 에 항목 한 덩어리 추가 (`dir` 은 `clinics/<폴더명>`)
2. `clinics/<폴더명>/` 폴더 생성 후 다른 파일만 복사
3. 링크는 `index.html?c=<지점id>` — 기본 지점(서울대입구점)은 파라미터 없이 기존 링크 그대로
